# Contributing to AIO Wallet Generator

First off, thank you for considering contributing to AIO Wallet Generator! It's people like you that make AIO Wallet Generator such a great tool.

## Where do I go from here?

If you've noticed a bug or have a feature request, make one! It's generally best if you get confirmation of your bug or approval for your feature before this.

## Fork & create a branch

If this is something you think you can fix, then fork AIO Wallet Generator and create a branch with a descriptive name.

## Implement your fix or feature

At this point, you're ready to make your changes. Feel free to ask for help; everyone is a beginner at first.

## Make a Pull Request

At this point, you should switch back to your master branch and make sure it's up to date with AIO Wallet Generator's master branch.
Then, push your feature branch to your fork, and create a Pull Request.

Please provide a clear description of the changes in the Pull Request.

## Code Style
- We use standard ES6 syntax.
- Please ensure that your code is clean, readable, and well-documented.
- Run tests (if applicable) before submitting the PR.

Thank you for your contribution!
