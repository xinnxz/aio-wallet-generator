# Security Policy

## Supported Versions

Currently, only the latest version of the AIO Wallet Generator is supported. We recommend always keeping your software up to date.

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Your security is our top priority. If you discover a security vulnerability within AIO Wallet Generator, please send an e-mail to the repository owner or open an issue on GitHub with the `security` label.

Please do not publicly disclose the vulnerability until it has been addressed.

All security vulnerabilities will be promptly addressed. Thank you for helping keep AIO Wallet Generator safe!
