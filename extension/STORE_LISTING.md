## Description

🔗 AIO Chain — The All-in-One Web3 Wallet Toolkit for Your Browser

Generate cryptocurrency wallets, validate addresses, and manage them securely — all without leaving your browser.

⚡ FEATURES:

🎯 Quick Wallet Generator
• Generate wallets for EVM, Solana, Bitcoin, and Tron
• Copy address or private key with one click
• Save to encrypted vault

🔍 Address Scanner
• Auto-detect crypto addresses on ANY webpage
• Colored highlights by chain type (blue for EVM, orange for Bitcoin)
• Hover to see chain info, click to copy
• Works on Etherscan, block explorers, forums, anywhere

📋 Right-Click Power Menu
• Select any text → right-click → "Validate Address"
• Instantly detect the chain and validity
• Generate QR codes for selected addresses

🔐 Encrypted Vault
• AES-256-GCM encryption with PBKDF2 key derivation
• Password-protected wallet storage
• Export your vault as a backup file
• Same military-grade encryption as our web app

⌨️ Omnibox Commands
• Type 'aio' in the address bar for quick commands
• aio gen → generate wallets
• aio val 0x... → validate an address
• aio qr 0x... → create a QR code

🔒 PRIVACY & SECURITY:
• 100% client-side — nothing is sent to any server
• No analytics, no tracking, no data collection
• Open source — every line auditable on GitHub
• Uses Web Crypto API (browser-native cryptography)

🌐 SUPPORTED CHAINS:
EVM (Ethereum, BSC, Polygon, Arbitrum, Avalanche) • Solana • Bitcoin • Tron • Sui • Aptos • Cosmos • TON • Starknet

📌 Also available as a full web app: https://aio-wallet-generator.vercel.app
