Getting Started

CLI Reference

Install globally or run with npx:

npm install -g web3-wallet-toolkit
# or
npx aio-chain <command>

generate

Generate wallets for any supported chain.

aio-chain generate [options]

Options:
  -c, --chain <chains>    Chain name(s), comma-separated        (default: "evm")
  -n, --count <number>    Number of wallets to generate         (default: 10)
  --hd                    Use HD wallet mode (single mnemonic)
  -o, --output <format>   Auto-export: csv, json, xlsx, encrypted
  -f, --file <path>       Output file path
  -p, --password <pass>   Password for encrypted export
  --show-keys             Show private keys in terminal

# Examples
aio-chain generate -c evm -n 100
aio-chain generate -c solana,bitcoin -n 50 -o csv
aio-chain generate -c evm -n 10000 --hd
aio-chain generate -c all -n 5 -o json -f wallets.json

validate

Validate crypto addresses with auto-detection.

aio-chain validate [addresses...] [options]

Options:
  -f, --file <path>             Read from file (one per line)
  --batch <addresses>           Comma-separated addresses

# Examples
aio-chain validate 0x742d35Cc6634C0532925a3b844Bc9e7595f2bD28
aio-chain validate --batch "0x742d...,5eykt...,bc1q..."
aio-chain validate --file addresses.txt

convert

Convert address formats (EVM checksum, lowercase, hex).

aio-chain convert <address> [options]

Options:
  -t, --to <format>    checksum, lowercase, uppercase, hex

# Examples
aio-chain convert 0x742d35cc... --to checksum
aio-chain convert 0x742d35cc...  # shows all formats

export

Export wallet data to various formats.

aio-chain export [options]

Options:
  -f, --format <format>    csv, json, xlsx, encrypted  (default: "json")
  -o, --file <path>        Output file path
  -i, --input <path>       Input wallet JSON file
  -p, --password <pass>    Password for encrypted

decrypt

Decrypt .encrypted wallet files.

aio-chain decrypt -f wallets.encrypted -p "your-password"
aio-chain decrypt -f wallets.encrypted -p "pass" -o csv

info

Show supported chains and their details.

aio-chain info
aio-chain info -c evm

Browser Extension

Generate up to 500 wallets at once. Progress bar, save all, copy all, export CSV.

Security Model

AIO Chain is designed with security as the top priority:

AspectImplementation
Architecture100% client-side. Zero server calls. Works offline.
Key Generationcrypto.getRandomValues() — OS-level CSPRNG
EVM Walletsethers.js v6 — audited, industry standard
Bitcoinbitcoinjs-lib v6 + tiny-secp256k1
Solana@solana/web3.js + tweetnacl Ed25519
EncryptionAES-256-GCM + PBKDF2 (100,000 iterations, SHA-256)
HD WalletsBIP39 mnemonic + BIP32/BIP44 derivation
Data StorageNothing stored. Generate → copy → gone. Vault encrypted locally.
Open SourceEvery line auditable on GitHub

Best Practices

  • Never share private keys or mnemonics
  • Use HD mode for deterministic backup (1 mnemonic = many wallets)
  • Export encrypted files with a strong password
  • Verify checksums of downloaded exports
  • Use the validator to confirm address integrity
