Getting Started

AIO Chain is available on 3 platforms. Choose the one that fits your workflow:

Web App

12-page dashboard with generator, validator, converter, QR, HD wallet, and more.

aio-wallet-generator.vercel.app

CLI Tool

6 commands for automation and scripting. Colored output, spinners, tables.

npx aio-chain generate -c evm -n 10

Browser Extension

Chrome/Edge/Brave. Vault, address scanner, context menu, omnibox.

chrome://extensions → Load unpacked

CLI Reference

Install globally or run with npx:

terminal 
# Install globally
npm install -g web3-wallet-toolkit
# Or run directly
npx aio-chain <command>

generate

Bulk wallet generation for any supported chain.

OptionDescriptionDefault
-c, --chainChain(s), comma-separatedevm
-n, --countNumber of wallets10
--hdHD wallet mode (BIP44)false
-o, --outputExport format: csv, json, xlsx, encrypted—
--show-keysShow private keys in terminalfalse
examples
aio-chain generate -c evm -n 100
aio-chain generate -c solana,bitcoin -n 50 -o csv
aio-chain generate -c evm -n 10000 --hd
aio-chain generate -c all -n 5 -o json

validate

Validate crypto addresses with auto-chain detection.

OptionDescription
addresses...One or more addresses
--batchComma-separated addresses
-f, --fileRead addresses from file
examples
aio-chain validate 0x742d35Cc6634C0532925a3b844Bc9e7595f2bD28
aio-chain validate --batch "0x742d...,5eykt...,bc1q..."
aio-chain validate -f addresses.txt

convert

Convert EVM address formats.

examples
aio-chain convert 0x742d35cc... --to checksum
aio-chain convert 0x742d35cc... # shows all formats

export

Re-export wallet files to different formats.

examples
aio-chain export -f xlsx -i wallets.json
aio-chain export -f encrypted -i wallets.json -p "pass"

decrypt

Decrypt .encrypted wallet files.

terminal
aio-chain decrypt -f wallets.encrypted -p "your-password"

info

Show all supported chains or details for a specific chain.

terminal
aio-chain info
aio-chain info -c cosmos

Browser Extension

Chrome MV3 extension with 5 power features:

1
Vault-First Security
Create a master password before accessing any features. AES-256-GCM encrypted storage.
2
Bulk Generate
Generate up to 500 wallets directly from the popup. Save, copy, or export as CSV.
3
Address Scanner
Content script that scans any webpage for crypto addresses with colored highlights.
4
Context Menu
Right-click any selected text → "Validate Address" or "Generate QR Code".
5
Omnibox
Type aio in the address bar for instant commands: aio gen eth 5
