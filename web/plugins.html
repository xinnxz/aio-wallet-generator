Plugin System

Extend AIO Chain with custom chains, exports, and validators.

Overview

AIO Chain's plugin system lets you add custom blockchain support, export formats, and validation logic without modifying core code.

Chain Plugins

Add any blockchain — just implement the generator interface.

generateWallet() → { address, privateKey }

Export Plugins

Custom export formats beyond CSV/JSON/XLSX.

exportWallets(wallets, options) → file

Validator Plugins

Custom address validation rules per chain.

validate(address) → { valid, chain }

Chain Plugin Interface

To add a new blockchain, create a module that exports these functions:

// plugins/my-custom-chain.js

export const chainConfig = {
  id: 'mychain',              // Unique identifier
  name: 'MyChain',            // Display name
  symbol: 'MYC',              // Token symbol
  addressPrefix: 'myc1',      // Address prefix
  keyType: 'Ed25519',         // Key algorithm
  networks: ['mainnet', 'testnet'],
};

/**
 * Generate a single wallet
 * @returns {{ address: string, privateKey: string, mnemonic?: string }}
 */
export async function generateWallet() {
  // Use crypto.getRandomValues() for key generation
  const privateKeyBytes = crypto.getRandomValues(new Uint8Array(32));
  const privateKey = '0x' + [...privateKeyBytes]
    .map(b => b.toString(16).padStart(2, '0')).join('');

  // Derive address from private key (chain-specific logic)
  const address = deriveAddress(privateKeyBytes);

  return { address, privateKey };
}

/**
 * Validate an address
 * @param {string} address
 * @returns {boolean}
 */
export function validateAddress(address) {
  return /^myc1[a-z0-9]{38}$/.test(address);
}

/**
 * Address regex for page scanner
 * @returns {RegExp}
 */
export function getScanPattern() {
  return /\bmyc1[a-z0-9]{38}\b/g;
}

Export Plugin Interface

// plugins/export-markdown.js

export const exportConfig = {
  id: 'markdown',
  name: 'Markdown Table',
  extension: '.md',
  mimeType: 'text/markdown',
};

/**
 * Export wallets to custom format
 * @param {Array} wallets - Array of wallet objects
 * @param {Object} options - { file, password }
 * @returns {string|Buffer} - File content
 */
export function exportWallets(wallets, options = {}) {
  let md = '| # | Chain | Address | Private Key |\n';
  md += '|---|---|---|---|\n';

  wallets.forEach((w, i) => {
    md += `| ${i + 1} | ${w.chain} | \`${w.address}\` | \`${w.privateKey}\` |\n`;
  });

  return md;
}

Registering Plugins

Plugins are registered in the core configuration:

// src/core/plugin-registry.js

import { chainConfig, generateWallet, validateAddress }
  from '../plugins/my-custom-chain.js';

// Register chain plugin
registerChain({
  ...chainConfig,
  generate: generateWallet,
  validate: validateAddress,
});

// Register export plugin
registerExport({
  id: 'markdown',
  name: 'Markdown Table',
  handler: exportWallets,
});

CLI Usage After Registration

# Generate with custom chain
aio-chain generate --chain mychain --count 10

# Export with custom format
aio-chain generate --chain evm --count 5 --output markdown
