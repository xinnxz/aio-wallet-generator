Plugin System

Extend AIO Chain with custom chains, export formats, and validators.

Plugin Types
Chain Plugin

Custom Blockchains

Add new chains with wallet generation, address validation, and scanner patterns.

Export Plugin

Custom Formats

Add export formats beyond CSV, JSON, XLSX — like PDF, YAML, or database connectors.

Validator Plugin

Custom Rules

Add validation rules: checksum algorithms, prefix checks, or chain-specific logic.

Chain Plugin Interface
chain-plugin.ts 
interface ChainPlugin {
  id: string;          // unique identifier
  name: string;        // display name
  symbol: string;      // ticker symbol
  color: string;       // brand hex color

  generateWallet(): Promise<Wallet>;
  validateAddress(addr: string): boolean;
  getScanPattern(): RegExp;
}
Export Plugin Interface
export-plugin.ts 
interface ExportPlugin {
  id: string;          // e.g. "pdf", "yaml"
  name: string;        // e.g. "PDF Export"
  extension: string;   // file extension

  exportWallets(
    wallets: Wallet[],
    options?: ExportOptions
  ): Promise<Blob | string>;
}
Validator Plugin Interface
validator-plugin.ts 
interface ValidatorPlugin {
  id: string;
  name: string;
  chains: string[];     // chains this validator applies to

  validate(address: string): ValidationResult;
}

interface ValidationResult {
  valid: boolean;
  chain?: string;
  checksumValid?: boolean;
  details?: string;
}
Plugin Registration
register.ts 
import { registerChain } from 'aio-chain/plugins';
import { MyChainPlugin } from './my-chain';

// Register at startup
registerChain(new MyChainPlugin());

// Now available via CLI:
// aio-chain generate -c mychain -n 10
