Offline

Self-Audit Checklist
All key generation uses CSPRNG (crypto.getRandomValues)
No private keys or mnemonics are transmitted over the network
No analytics, tracking scripts, or telemetry of any kind
Encrypted exports use AES-256-GCM with authenticated ciphertext
PBKDF2 key derivation with 100,000 iterations (SHA-256)
Random salt and IV per encryption — no ciphertext reuse
Extension vault uses chrome.storage.local with AES-256-GCM
Service worker and CSP prevent external script injection
Best Practices
Use HD Mode
One mnemonic phrase backs up all wallets. Easier recovery, same security level.
Encrypt Exports
Always export with encryption enabled. Use a unique, strong password per file.
Generate Offline
For maximum safety, disconnect from internet before generating wallets.
Verify Addresses
Use the validator tool to confirm address checksums before sending funds.
Store Securely
Keep private keys on encrypted drives or hardware. Never in plaintext files.
Audit the Source
Read the code. Every line is open source. No obfuscation, no minification in source.
