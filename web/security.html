Architecture

All cryptographic operations run in your browser or terminal. Zero server calls. No API keys. Works offline.

Zero Data Collection

No analytics, no tracking, no cookies, no telemetry. We don't know who you are or what you generate.

Open Source

No Dependencies at Runtime

Web app loads from static files. No CDN dependencies for crypto operations. Extension uses Web Crypto API only.

Self-Audit Checklist

Verify the security yourself — every item is checkable in the source code:

✓
No external API calls

Search codebase for fetch( or XMLHttpRequest — none found in core wallet logic.

✓
CSPRNG for key generation

All private keys use crypto.getRandomValues(), never Math.random().

✓
Keys never leave the browser

No localStorage writes for keys (web app). Extension vault encrypts before storing.

✓
Industry-standard libraries

ethers.js, bitcoinjs-lib, @solana/web3.js — widely audited, used by millions.

✓

✓
No analytics or tracking scripts

No Google Analytics, no Sentry, no Mixpanel, no tracking pixels.

✓

Best Practices

Use HD Mode

1 mnemonic = unlimited wallets. Easier to backup and recover. Use --hd flag in CLI.

Export Encrypted

Always use --output encrypted for sensitive exports. Never save plain-text keys.

Verify Checksums

Use the Validate tool to confirm address integrity before sending funds.

Offline Generation

For maximum security, disconnect from internet before generating wallets. The app works 100% offline.

Vault Password

Extension vault uses 100K PBKDF2 iterations. Use a strong, unique password (12+ chars).

Self-Host

Clone the repo, run locally. npm run dev — full control, zero trust required.
